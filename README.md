# Waypoint

**Keyboard-first navigation for large Excel models.**

Waypoint is a floating panel that lets you move around big financial models without touching the mouse. It's a single add-in file, written in pure VBA, and needs no admin rights.

## Features

- **Search** sheets, pins and recent places, or type a cell reference (`Debt!C5`) to go straight there.
- **Find a word** inside any sheet and step through every match.
- **Arrow keys** step through sheets, and `Home` / `End` jump to the top-left / last used cell.
- **Back / Forward** through every jump you've made.
- **Pins and a bookmark** for the ranges you keep coming back to. `Ctrl+B` jumps there and back.
- **Change markers** show which sheets have unsaved edits or differ from the last version.
- **Versions share a workspace**, so v17 and v18 of a model keep the same pins.
- **Macro map (optional)** lists the ranges your macros read and write.

## Install

1. Copy `Waypoint_deployed.xlam` to `%APPDATA%\Microsoft\AddIns\`.
2. In Excel, go to **File > Options > Add-ins > Manage: Excel Add-ins > Go…**, tick **Waypoint**, then OK.
3. Press `Ctrl+Q` in any workbook.

If Excel blocks it, right-click the file, choose **Properties**, and tick **Unblock**.

| Key | Action |
|---|---|
| `Ctrl+Q` | Open the panel |
| `←` / `→` | Previous / next sheet |
